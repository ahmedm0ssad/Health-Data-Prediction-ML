Comparison of classical machine learning and neural network models on a health dataset, including KNN, SVM, Logistic Regression, Linear Regression, and Neural Networks.

## Overview

- **EDA** — health data exploration and visualization with Pandas/Seaborn/Matplotlib.
- **Models compared** — K-Nearest Neighbors, Support Vector Machines, Logistic Regression, Linear Regression, and Neural Networks (TensorFlow/Keras).
- Evaluation of model performance on held-out health records.
